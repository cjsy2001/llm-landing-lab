# llm-landing-lab

A hands-on path from demo to production LLM app: an HR assistant built on the perceive-reason-remember-act architecture, growing from basic RAG to Agentic RAG with multi-hop retrieval, deployed on Azure.

**Status:** specification. See [`specs/001-llm-landing-lab/`](specs/001-llm-landing-lab/).

## Local setup

```
make setup      # enable the gitleaks pre-commit hook
make gitleaks   # full-history secret scan (docker)
```
